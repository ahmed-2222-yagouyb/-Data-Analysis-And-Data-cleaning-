
  excel  مشروع تنظيف وتحليل بيانات المبيعات باستخدام

نبذة عن المشروع

يهدف هذا المشروع إلى تنظيف بيانات المبيعات وتحليلها باستخدام Microsoft Excel، واستخراج مؤشرات تساعد على فهم أداء المبيعات واتجاهاتها، من خلال إنشاء لوحة معلومات تفاعلية (Dashboard).

أهداف المشروع

- تنظيف البيانات وتجهيزها للتحليل.
- اكتشاف السجلات المكررة ومعالجتها.
- معالجة القيم الفارغة وغير الموحدة.
- توحيد تنسيق التواريخ.
- تحليل المبيعات حسب الأشهر والمدن.
- تحديد أعلى شهر من حيث المبيعات.
- تحديد أفضل ثلاث مدن من حيث المبيعات.
- إنشاء لوحة معلومات تفاعلية لعرض النتائج.

الأدوات المستخدمة

- Microsoft Excel 2016
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Excel Formulas

خطوات تنظيف البيانات

1. إزالة السجلات المكررة.
2. معالجة القيم الفارغة في بيانات المدن.
3. توحيد القيم غير المحددة.
4. معالجة اختلاف تنسيقات التواريخ.
5. تجهيز البيانات للتحليل.

نتائج التحليل

- إجمالي المبيعات: 164,761
- أعلى شهر من حيث المبيعات: مارس، بقيمة 34,967.
- أقل شهر من حيث المبيعات: أغسطس، بقيمة 512.
- تحديد أفضل ثلاث مدن من حيث إجمالي المبيعات.
- إنشاء رسم بياني يوضح اتجاه المبيعات الشهرية.

لوحة المعلومات التفاعلية

تم إنشاء Dashboard باستخدام Excel لعرض:

- إجمالي المبيعات.
- أفضل شهر من حيث المبيعات.
- أفضل ثلاث مدن.
- اتجاه المبيعات الشهرية.
- إمكانية التفاعل مع النتائج باستخدام Slicer.

مخرجات المشروع

- ملف Excel يحتوي على البيانات المنظفة والتحليلات ولوحة المعلومات.
- ملف PDF لعرض نتائج المشروع.
- التقرير الختامي لعمليات تنظيف البيانات والتحليل.

الخلاصة

ساهم المشروع في تحويل بيانات المبيعات الخام إلى بيانات منظمة وقابلة للتحليل، واستخدام أدوات Excel لاستخراج مؤشرات الأداء وعرض النتائج بصورة واضحة وتفاعلية.
